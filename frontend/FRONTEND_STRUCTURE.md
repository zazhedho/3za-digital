# Frontend Structure

Structure follows `safety-riding/frontend`:

- `src/components/common`: shared layout, loading, modal, protected route.
- `src/contexts`: auth and theme context.
- `src/hooks`: permission helpers.
- `src/pages`: auth, dashboard, SMM, wallet, admin, user pages.
- `src/services`: Axios API clients.
- `src/styles`: design system and theme CSS.
- `public`: static assets.
